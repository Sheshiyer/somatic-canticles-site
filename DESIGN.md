# Somatic Canticles Landing: Design Token Contract

This is the token contract for `site/styles.css`. Every color, font, size, space, radius and motion value used in the stylesheet must come from the `:root` block below. If you add a token, document it here and, for colors, add its pairs to `scripts/contrast.ts`.

- **Identity source:** bm-wiki "Bioluminescent Architecture" (`_sources/bm-wiki/src/content/docs/brand/visual-guidelines.md`, `src/data/site-data.json`).
- **Motion source:** `_sources/bm-wiki/src/content/docs/marketing/video-scripts.md`, "Motion Direction".
- **Product context:** `PRODUCT.md`.

## Color

The five brand tokens are fixed. I derived exactly three tokens from them, and each is documented with its reason.

| Token | Hex | Role | Share |
|---|---|---|---|
| `--void` | `#0A1628` | Void Teal. Page background | ~60% |
| `--cream` | `#F0EDE3` | Phosphor Cream. Body text, headings | ~30% |
| `--bronze` | `#C4873B` | Solar Bronze. Accent: primary CTA fill, links, eyebrows, chapter markers, sigils | ~10% |
| `--titanium` | `#8A9BA8` | Titanium. Metadata, captions, provenance, colophon, control borders and hairlines | as needed |
| `--chlorophyll` | `#4A7C59` | Chlorophyll. Living-system moments: **graphic strokes only** (ECG line, vine motif, success tick). At 3.73:1 on void it is **never used for text** | sparing |

**Derived tokens (3 of 3 allowed):**

| Token | Hex | Derived from | Why |
|---|---|---|---|
| `--void-raised` | `#12233B` | `--void`, lifted about 4% lightness toward cream | A surface for cards, the sample panel and form fields; it separates planes without borders. |
| `--bronze-bright` | `#D9A25E` | `--bronze`, a tint toward cream | Hover and active states for the primary CTA and links, and the focus ring (8.01:1 on void). |
| `--chlorophyll-bright` | `#7DB38E` | `--chlorophyll`, a tint toward cream | The text-safe version of the living color, for form success messages and the companion-app note (7.52:1 on void). |

**Rules**
- There are no gradients between brand hues and no glow blobs.
- "Luminous" is expressed as a light bloom within one hue: for example `radial-gradient` from `color-mix(in oklab, var(--bronze) 18%, transparent)` to `transparent`, used behind the film tile only.
- Hairlines use `color-mix(in oklab, var(--titanium) 35%, transparent)`. They are decorative only; any control border uses solid `--titanium` (3:1 rule).
- Text on imagery sits on a solid `--void` or `--void-raised` plate, never directly on busy art.

### Font loading (glyph-checked)

I checked this on 2026-09-26 by fetching Google Fonts CSS2 with a desktop Chrome/150 UA.
- Every family and weight is served a `latin-ext` subset whose `unicode-range` starts `U+0100-02BA`, which covers **U+0113 (ē)**: Cinzel 400/700, EB Garamond 400/400i/600, Fira Code 400/500.
- All `latin-ext` woff2 files return HTTP 200.
- Cinzel is a variable font: 400 and 700 share one file (14.5 KB latin-ext).

"Khalorēē" therefore renders in the display, body and mono families without a fallback glyph.

Paste into `<head>` before `styles.css`:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Cinzel:wght@400;700&family=EB+Garamond:ital,wght@0,400;0,600;1,400&family=Fira+Code:wght@400;500&display=swap">
```

## Motion

The motion direction comes from `video-scripts.md`: "slow parallax over static art rather than fast montage", with sparse, large typography. Bronze and phosphor accents carry the brand signal. `visual-guidelines.md` adds that motion reveals hierarchy and pacing and never competes with long-form prose.

| Token | Value | Use |
|---|---|---|
| `--dur-fast` | `160ms` | Hover and focus color, button press |
| `--dur-base` | `320ms` | Control state changes (play/pause icon, mute label) |
| `--dur-reveal` | `900ms` | Scroll-reveal fade-up (translateY 24px → 0, opacity 0 → 1), once per element |
| `--dur-drift` | `24s` | Ambient "breath" on the light bloom behind the film (opacity 0.7 ↔ 1), alternate, infinite |
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | Reveals and entrances |
| `--ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | State swaps |
| `--ease-breath` | `cubic-bezier(0.37, 0, 0.63, 1)` | Ambient drift (sine-like) |
| `--parallax-max` | `6%` | Maximum translate of cover art against scroll; static art only, never text |
| `--stagger` | `120ms` | Delay between sibling reveals (book cards, Somanaut names) |

**Rules**
- There is no fast montage, bounce, spring overshoot, glitch or shake.
- Only `transform` and `opacity` are animated.
- Text is never parallaxed. Only static art moves: covers and the trilogy plate.
- The `#sample` section has no motion at all once it is in view.

**Reduced-motion policy** (`@media (prefers-reduced-motion: reduce)`):
- The hero `<video>` does not autoplay. `main.js` calls `pause()` then `load()`, so the poster frame shows with the play button visible; playback starts only on a user click. This follows the brag pattern.
- All reveals render in their final state, and parallax and the drift animation are removed.
- Every `transition-duration` and `animation-duration` collapses to `0.01ms`.
- `scroll-behavior: auto`.
- Sound always starts muted regardless of motion setting, and is unmuted only by the user.
